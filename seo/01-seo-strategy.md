## 1. 目標與 KPI

| 提升品類自然流量 | 「沙發 / 模組沙發 / 設計家具 / 床墊」相關查詢的曝光與點擊 | 每月 |

## 2. 關鍵字研究框架

依**購買漏斗**分層，每層對應不同頁面類型：

### TOFU（認知，資訊型 → 部落格 / 指南）
- 沙發怎麼挑、沙發尺寸怎麼量、模組化沙發優缺點
- 貓抓布 vs 貓抓皮、布沙發 vs 皮沙發、沙發深度幾公分舒適
- 實木桌保養、床墊軟硬怎麼選、小坪數客廳家具配置
- 居家佈置技巧、北歐風 / 無印風客廳搭配

### MOFU（評估，比較型 → 比較文 / 分類頁）
- 模組化沙發推薦、台灣設計家具品牌推薦
- STIMLIG vs 走走家具 / Plus mofa / YKS（誠實比較，見 03）
- 設計沙發品牌比較、台灣製沙發推薦

### BOFU（決策，交易型 → 產品 / 分類 / 門市頁）
- 島嶼沙發 / 音符沙發 / Boon Chair / AMIS 茶几 / CLOUD 9 床墊（品牌詞 + 型號）
- 模組沙發訂製、設計家具 台北/台中/台南、家具展示間 預約
- 沙發 訂製 顏色、客製沙發

### 品牌詞（保護 + 擴張）
- STIMLIG、STIMLIG 沙發、STIMLIG 評價、STIMLIG 門市、巴雷扶手椅

> **執行**：用 GSC「成效 → 查詢」找出**已在第 5–20 名**的詞（最快見效的低垂果實），
> 優先優化對應頁面。再用關鍵字工具（Ahrefs / Semrush / Ubersuggest / Google Keyword Planner）
> 補足量與難度，建立關鍵字地圖（keyword → 對應 URL → 目標排名）。

## 4. 網站架構與 URL

目前內容文章散落在根目錄（`/house-decoration-tip/`、`/amisdesign/`…），缺乏主題集群與麵包屑層級。

**建議**（WordPress 可由 SEO 外掛 + 301 達成，避免亂改既有 URL）：

- **保留既有 URL，不要為了「漂亮」大規模改網址**——除非有完整 301 對照，否則風險大於收益。
- 改善的是**內部連結與導覽結構**，而非實體路徑：建立主題中心頁（Hub），由 Hub 連向相關指南與產品。
  - 例：「沙發選購指南中心」→ 連向沙發挑選全指南、模組沙發優缺點、布料比較 → 再導向島嶼/音符沙發產品頁。
- 確認 WooCommerce 分類 / 商品的麵包屑（BreadcrumbList schema）正確。
- 分頁、篩選（顏色 / 材質）參數頁需處理 canonical，避免重複內容稀釋。

## 5. On-page 優化標準

每個目標頁面建立並檢查：

- **Title**：`主關鍵字 ｜ 賣點 ｜ STIMLIG`，控制在約 30 字內（中文）／60 字元（英文）。
- **Meta description**：含主關鍵字 + 行動呼籲，約 70–80 字，誘發點擊（非排名因素但影響 CTR）。
- **H1 唯一**，自然包含主關鍵字；H2/H3 對應子主題與長尾詞。
- **圖片**：產品圖檔名語意化、`alt` 描述含關鍵字；壓縮 + 次世代格式（見 02）。
- **內部連結**：每篇指南至少連 2–3 個相關產品/分類頁，錨文字用目標關鍵字。
- **產品頁**：完整規格表（尺寸/材質/模組數/保固）、客製選項說明、FAQ 區塊、評價/見證。

### On-page 檢查清單（每頁套用）
- [ ] Title 含主關鍵字且未截斷
- [ ] Meta description 已撰寫、含 CTA
- [ ] 唯一 H1、H2 結構清楚
- [ ] 圖片 alt 與檔名已優化
- [ ] 內部連結（出站 + 入站）已建立
- [ ] 對應 schema 已套用（見 02）
- [ ] 行動裝置可讀、無破版
